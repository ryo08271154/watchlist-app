# 視聴記録アプリ

[視聴記録](https://github.com/ryo08271154/watchlist)のアプリケーションです。
視聴記録をスマートフォンでも快適に利用できるようにするためのアプリです。

## 使い方

アプリを起動し、表示される画面から視聴記録を確認します。
オフライン時でも一部の情報を確認できるため、外出先でも利用できます。

## ダウンロード

- **Android**
  - [GitHub Releases](https://github.com/ryo08271154/watchlist-app/releases/latest)
    - "Assets" から `apk` をダウンロードし、端末にインストールしてください。
- **iOS**
  - 現在、iOS版は公開されていません。

## 権限

アプリケーションは以下の権限を使用します

- **Android**:
  - `android.permission.READ_CALENDAR` - カレンダーへの読み取り
  - `android.permission.WRITE_CALENDAR` - カレンダーへの書き込み
